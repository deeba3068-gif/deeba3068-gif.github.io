# Deeba — Modern Portfolio

A responsive, GitHub Pages-ready portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save. GitHub will generate your live portfolio URL.

## Easy edits
- Main content: `index.html`
- Design/colours/layout: `style.css`
- Animations/interactions: `script.js`
- Portfolio photos: `assets/`
